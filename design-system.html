Princípios

Adaptamos os três pilares da HIG — clareza, deferência e profundidade — para um app pessoal que se usa várias vezes ao dia.

Clareza

Texto legível, ícones simples, hierarquia por tamanho e peso, não por cor. Uma ação principal por tela.

Deferência

A interface some para o conteúdo aparecer. Fundos agrupados, listas sem molduras pesadas, cor só para dar significado.

Profundidade

Camadas com materiais translúcidos (barra de abas, sheets) e movimento com mola para mostrar de onde as coisas vêm.

Toque

Alvo mínimo de 44pt. Gestos conhecidos: deslizar para mudar de dia, sheets que sobem de baixo.

Cores

Cores do sistema com variantes automáticas para claro e escuro. Nunca use hexadecimal no componente: use o token.

Tipografia

SF Pro (via -apple-system) com a escala do Dynamic Type. Pesos: regular (400), semibold (600) e bold (700). Tamanho do texto de corpo: 17px.

Espaço, cantos e movimento

Grade de 4pt. Margem lateral de 16px. Cantos contínuos (squircle) quando o navegador suporta.

Movimento: --dur-fast 150ms (toque), --dur 300ms (transições), --ease-spring para elementos que “ganham vida” (check, abas). Respeita “reduzir movimento”.

Padrões e regras

  • Uma cor de destaque (--tint, índigo) para ações e seleção. Cores de área/humor só para categorizar.
  • Cor nunca sozinha: sempre acompanhada de texto, ícone ou posição (acessibilidade).
  • Listas agrupadas para qualquer coleção de itens; cards só para blocos independentes (meta, hábito, área).
  • Sheets de baixo para criar e editar; confirmação só em ações destrutivas.
  • Texto sempre em tokens --type-*. Não crie tamanhos novos.
  • Sem sombras fortes em conteúdo; elevação só em itens flutuantes (botão +, avisos).
  • Contraste: texto secundário usa --label-2; nunca --label-3 para informação importante.
